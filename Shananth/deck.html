What is slopsquatting?

Typosquatting

Bets on a human typo.

reqeusts

A misspelling of a real name.

Slopsquatting

Bets on the AI's mistake.

react-codeshift

A confident, plausible name the model invents.

    An assembly line for code. Every change passes automatic quality checks on its way to users.
    
    
    
      
    
        
    ✓01Code changesomeone pushes
    
        
    ✓02Buildinstall & assemble
    
        
    ✓03Testrun the checks
    
        
    ✓04Deployship to users

        • 
          
      • ✗Only one release

      Best practices, in three layers
      
    
      
      
      
        PREVENT
      You, using AI
      
        
        
          
      • Look the name up on the registry before installing.
        • 
          
      • Copy install commands from official docs.
        • 
          
      • Give your AI tool a rule:
        # AGENTS.md
Only use packages already
in the project. Ask before
adding a new one.
        • 
        
      
      
      
      
      
        PREVENT + CONTAIN
      Your project and pipeline
      
        
        
          
      • Install only what the lockfile approvesGATE 1
        npm ci
composer install  # uses composer.lock
pip install --require-hashes -r requirements.txt
        • 
          
      • Hold back brand-new releases for a weekGATE 3
        min-release-age=7  # .npmrc, in days
# composer.json, under "config":
"policy": {"cooldown": {"period": "7 days"}}
        • 
          
      • Don't let install scripts run by defaultGATE 4
        ignore-scripts=true  # .npmrc
"allow-plugins": {…} # Composer: only listed run
        • 
        
      
      
      
      
      
        CONTAIN
      Your AI agents
      
        
        
          
      • Require approval before any install command.
        • 
          
      • Run agents in a sandbox or container.
        • 
          
      • No real passwords or keys where agents or installs run.
        • 
        
      
      
      
    
      
    
      Not enough on its own: CVE scanners (a new fake has no report yet) · signatures (prove who built it, not that you wanted it) · download counts (easy to fake)
      
  
      

  
  
      
    
      Already installed one?
      
    
        
      
      1. 1Remove it
        Uninstall it and restore your lockfile from before it was added.
        2. 
      
      2. 2Change every secret
        Assume every password, key and token that machine or pipeline could reach is stolen. Replace them.
        3. 
      
      3. 3Check what else changed
        Lockfile changes, recent builds, new files, unexpected network traffic.
        4. 
      
      4. 4Report it
        npm and PyPI: the "Report malware" button on the package page. Packagist: its contact page.
        5. 
    
      
  
      

  
  
      
    
      Three things to keep
      
    
      1
      Treat AI-suggested package names as untrusted input.
      
    
      2
      Pin dependencies with hashes, so unknown names fail by default.
      
    
      3
      Never let agents or scanners install packages where real credentials live.
