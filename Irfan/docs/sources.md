| One real person said "yes, that's me" | **The Mom Test**, Rob Fitzpatrick. Talk about their life, not your idea; ask about specific past events; listen more than you talk. Summary: https://www.ybrikman.com/blog/2023/03/29/the-mom-test/ | Secondary summaries only; book not opened. |
| Riskiest assumption + one cheap test | **Lean Startup**, Eric Ries: begin with leap-of-faith assumptions and test them with a minimum viable product. The "riskiest assumption test" name is a later framing (David Bland, Jeff Higham), not Ries's own term. Summary: https://resources.rework.com/libraries/startup-fundamentals/riskiest-assumption-test | Secondary; naming is a later interpretation. |
| Risks, written before building (worksheet) | **Premortem**, Gary Klein, "Performing a Project Premortem", Harvard Business Review 85(9), Sept 2007: assume the project already failed and list why. Overview: https://en.wikipedia.org/wiki/Pre-mortem | Citation confirmed; HBR article itself not opened. |
| Version 1 fits a time box | **Appetite**, Basecamp "Shape Up": fixed time, variable scope. Primary: https://basecamp.com/shapeup/1.2-chapter-03 | Primary page found. |
| Loop cap (3 rounds) | My own rule of thumb for a beginner talk, not from a source. | Opinion. |
